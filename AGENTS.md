# Project notes

- Astro 7 static site, Node 22 (`nvm use`). Commands: `npm run dev`, `npm run build`, `npm run check`.
- Content rules: public copy is English; never invent facts, metrics, quotes, languages or titles. Every fact in `src/data/facts.ts` carries source ids that exist in `src/data/sources.ts`; unverified items go to `docs/PENDING.md`, never to the page as placeholders.
- Style rules: no em or en dashes in text, no italic headings, no tiny uppercase labels, no cards or badge rows. Palette is marble, warm greys and charcoal only. Light and dark sections alternate.
- Animation tuning lives in `src/config/animation.ts`. Frames are generated by `npm run frames`; do not hand-edit `public/frames/` or `src/config/frames.json`.
- Verify the opening scene at 1440x900, 390x844 and 360x740, with `prefers-reduced-motion`, and with the pause button.
- Server pieces: `src/lib/` (db, auth, article model), `src/pages/admin`, `src/pages/api/admin`, `src/middleware.ts` (guards `/admin` and `/api/admin`). Admin UI copy is in Spanish on purpose (Diego is its only user); the public site is English.
- Vercel project `diego-portfolio` (team carlos-projects) is linked via `.vercel/`. Never print or commit `.env*`.
